# Comunidade da Rede Social Brasileira

Este repositório reúne o perfil e as orientações de colaboração da organização
[Rede Social Brasileira](https://github.com/rede-social-brasileira).
O nome é provisório. O projeto está em pesquisa e definição de produto.

## Documentos

- [Perfil da organização](profile/README.md).
- [Como contribuir](CONTRIBUTING.md).
- [Código de conduta](CODE_OF_CONDUCT.md).
- [Segurança e relatos privados](SECURITY.md).
- [Dúvidas e suporte](SUPPORT.md).
- [Governança e decisões pendentes](GOVERNANCE.md).

O GitHub pode usar `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`,
`SUPPORT.md` e os modelos como padrão nos repositórios da organização que não
tenham seus próprios arquivos do mesmo tipo. As instruções técnicas de cada
produto ficam no respectivo repositório.

O planejamento interno está privado durante a revisão. Os documentos e as
decisões destinados à comunidade serão publicados depois de revisados.

## Escopo e licença

Este repositório contém documentação e modelos de colaboração. O código do
produto será publicado em uma etapa própria, após revisão.

A licença deste repositório ainda não foi escolhida. A licença do futuro código
do produto também continua pendente. Esta publicação não define esses termos.

Cada repositório terá sua própria decisão de licença; o GitHub não usa um
`LICENSE` da organização como licença padrão dos demais repositórios.
